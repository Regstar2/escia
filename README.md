# Эсция — атлас и хроники мира

Публичный макет сайта авторского D&D-сеттинга: мир **Эсция**, основной континент **Астеран**, кампания **«Время смертных»**.

## Локальный запуск

Нужен любой статический HTTP-сервер. Например, из корня репозитория:

```powershell
python -m http.server 8080
```

После запуска откройте `http://localhost:8080/`.

Сайт создан на HTML, CSS и JavaScript без обязательных зависимостей и сборки; подходит для последующей публикации через GitHub Pages.

## Разделы

- Главная и карта оригинальной географии Астерана.
- Энциклопедия с поиском по публичным статьям.
- Кампания и первая глава «Сердце леса».
- Галерея (начальная версия).

## Карта

Растровые изображения `assets/political.webp` и `assets/terrain.webp` получены из `.map`, предоставленного автором, без изменения береговой линии и границ. Политический вариант использует оригинальные географические контуры, государства и надписи. Географический вариант скрывает политическую окраску и надписи. Масштабирование и перетаскивание выполняются на клиенте.

Сам исходный файл `.map` **не публикуется**: до публикации нужно отдельно проверить, не содержит ли он скрытые объекты или мастерские заметки.

Полноценный просмотр слоёв Azgaar и связка интерактивных полигонов со статьями пока не реализованы.

## Безопасность лора

Материалы мастера находятся в приватном репозитории и не копируются в публичный сайт. В макете представлены только публичные сведения о мире и завязке первой истории. Не копируйте `docs/session-01` из мастерского репозитория целиком.

## Публикация

После утверждения дизайна GitHub Pages можно настроить на публикацию из корня ветки `main` (Settings → Pages → Deploy from a branch → main / root). Для корневого пути `https://regstar2.github.io/escia/` относительные ссылки на ресурсы работают без перенастройки.

## Текущий статус

**Макет / прототип, не готовая энциклопедия.** Изображения государств и портреты можно добавить после согласования публичной подборки. Названия и факты не выводятся автоматически из приватной документации.
